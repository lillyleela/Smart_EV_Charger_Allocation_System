# Smart EV Charger Allocation System

## Project Overview

The Smart EV Charger Allocation System is a Java-based
application designed to manage electric vehicle charging
stations and allocate available chargers to registered
electric vehicles.

The system helps manage charger availability, charging
requests, charging sessions, waiting queues, and payment
calculations.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- VS Code

## Modules

1. User and Vehicle Management
2. Charger and Station Management
3. Charging Request Management
4. Charger Allocation
5. Charging Session Management
6. Waiting Queue and Payment Management

## OOP Concepts Implemented

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Classes and Objects
- Exception Handling

## Key Features

- User registration and login
- Vehicle registration
- Charger availability management
- Normal, Fast and Super Fast charger types
- Automatic charger allocation
- Charging session management
- Charging cost calculation
- Waiting queue management
- Payment status management

## How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Compile the Java source files.
4. Run the main class of the application.

## Project Type

Java Console-Based Application
